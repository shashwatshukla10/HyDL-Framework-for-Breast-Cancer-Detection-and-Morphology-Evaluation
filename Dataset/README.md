## Dataset Description 
### 1. BUSI Dataset
The Breast Ultrasound Images (BUSI) dataset is used as the primary dataset for training and testing the proposed Hybrid Deep Learning framework for breast cancer detection and segmentation. The dataset contains breast ultrasound images categorized into benign, malignant, and normal classes, along with their corresponding tumor mask annotations. It is utilized for model development, segmentation learning, classification analysis, and performance evaluation of the proposed framework.

The dataset can be downloaded from the following source:

- [Kaggle Dataset Repository](https://www.kaggle.com/datasets/anaselmasry/datasetbusiwithgt/data)


### 2. BUSBRA Dataset
The BUSBRA dataset [[135]](https://aapm.onlinelibrary.wiley.com/doi/10.1002/mp.16812) is used for external validation to evaluate the generalization capability and robustness of the proposed Hybrid Deep Learning framework on unseen breast ultrasound images. The dataset enables cross-dataset validation by assessing the performance consistency of the trained model under different imaging characteristics, lesion distributions, and acquisition conditions. The external validation results demonstrate the capability of the proposed framework to maintain reliable performance beyond the primary training dataset.

The dataset is publicly available through the following sources:

- [Zenodo Dataset Repository](https://zenodo.org/records/8231412)
- [Official GitHub Repository](https://github.com/wgomezf/BUS-BRA)
